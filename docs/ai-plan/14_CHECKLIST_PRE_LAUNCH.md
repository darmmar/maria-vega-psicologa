# Checklist pre-lanzamiento

## Técnica

- [ ] Build funciona.
- [ ] No hay errores TypeScript.
- [ ] No hay secretos en el repo.
- [ ] Sitemap generado.
- [ ] Robots configurado.
- [ ] Canonical correcto.
- [ ] OpenGraph correcto.
- [ ] Imágenes optimizadas.
- [ ] Mobile correcto.
- [ ] Lighthouse revisado.
- [ ] Accesibilidad básica revisada.

## SEO

- [ ] Title único por página.
- [ ] Description única por página.
- [ ] H1 único por página.
- [ ] Enlaces internos.
- [ ] Página `/psicologa-malaga`.
- [ ] Página `/terapia-online`.
- [ ] Página `/terapia-duelo`.
- [ ] Página `/terapia-ansiedad`.
- [ ] Recursos iniciales publicados.
- [ ] JSON-LD validado.
- [ ] Search Console preparado.
- [ ] Sitemap enviado.

## Legal y privacidad

- [ ] Aviso legal.
- [ ] Política de privacidad.
- [ ] Política de cookies.
- [ ] Checkbox de privacidad si hay formularios.
- [ ] Aviso de no incluir información clínica sensible.
- [ ] No se recogen datos clínicos en formularios.
- [ ] No hay analytics invasivo sin consentimiento.

## Reservas

- [ ] Cal.com creado.
- [ ] Tipos de evento creados.
- [ ] Google Calendar sincronizado.

## Pagos

- [ ] Stripe Payment Link creado si procede.
- [ ] CTA del curso funcionando.
- [ ] Flujo de pago probado.
- [ ] Email de confirmación revisado.

## Deploy

- [ ] Repo conectado a Vercel.

- [ ] DNS correcto.
- [ ] Preview revisada.
