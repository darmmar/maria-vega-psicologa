# Plan IA — Web María Vega Psicología

Copia esta carpeta dentro del repositorio, preferiblemente en:

```txt
docs/ai-plan/
```

Después abre Cursor y pega el contenido de:

```txt
00_START_HERE_CURSOR_PROMPT.md
```

## Stack decidido

```txt
Astro + TypeScript + Tailwind CSS + MDX + TinaCMS + Cal.com + Stripe Payment Links + Vercel + dominio propio
```

## Flujo de trabajo

```txt
Stitch MCP → diseño y especificación visual
Cursor → implementación por fases
GitHub → control de versiones
Vercel → despliegue
TinaCMS → edición de contenido
Cal.com → reservas
Stripe Payment Links → pagos externos
```

## Regla principal

Cursor debe trabajar por fases, no hacerlo todo de golpe:

1. Planificar leyendo esta carpeta y consultando Stitch.
2. Crear rama.
3. Implementar una fase.
4. Ejecutar build.
5. Commit.
6. Esperar confirmación para la siguiente fase.
