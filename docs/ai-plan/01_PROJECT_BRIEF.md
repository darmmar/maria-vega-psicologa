# Brief del proyecto

## Objetivo

Crear una web elegante, cálida, rápida, editable y SEO-friendly para una psicóloga sanitaria en Málaga.

## Mensaje base

```txt
María Vega Psicología
Psicóloga en Málaga y terapia online.
Terapia contextual, ACT y terapia breve sistémica para problemas emocionales, relacionales, duelo, ansiedad, autocuidado y adicciones.
Atención a adultos, adolescentes y niños desde una perspectiva de género y basada en evidencia científica.
```

Incluirlo como formación complementaria, no como formación clínica principal. Puede reforzar bienestar laboral, estrés, autocuidado, orientación y comprensión de contextos organizacionales.
